# Contribution

Ce dépôt est publié comme **vitrine de portfolio** : le code correspond à un projet académique (SAE) et est mis à disposition **à titre d’illustration**.

- Les **pull requests** et l’ouverture de **tickets pour faire évoluer** le projet ne sont en général pas attendues.
- Vous pouvez **forker** le dépôt pour expérimenter ou réutiliser des idées dans vos propres projets, en respectant la [licence](LICENSE).

Pour signaler un problème de sécurité (fuite de secrets, vulnérabilité), préférez un message privé au mainteneur plutôt qu’une issue publique.
